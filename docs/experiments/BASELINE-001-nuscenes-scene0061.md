# BASELINE-001：OmniRe / nuScenes scene-0061 / step 29,381

实验日期：2026-10-31 至 2026-11-01。整理日期：2026-11-07。

## 1. 基线结论

本报告仅保留 **29,381 步最终模型** 作为后续实验的基线。已完成数据预处理、分割掩码、SMPL 接入、云端联合训练、正式评估、效果视频导出及归档。

留出集：PSNR **24.0793 dB**、SSIM **0.7607**、LPIPS **0.2206**。本轮是单场景历史基线，没有独立算法对照组，不能据此认定某项优化有效，也不能视为论文完整基准复现。

## 2. 优化项目与实验目的

本轮项目是“在 nuScenes scene-0061 上建立可运行、可评估、可复用的 OmniRe 基线”。主要解决数据接入、语义掩码与 SMPL 资产准备、运行环境兼容、训练恢复及成果归档问题。

已跑通背景、刚体、SMPL 人体和可形变节点的联合训练，并使用 Sky、Affine、CamPose 模块。历史运行增加了定时保存退出、原子检查点和恢复兼容修复；这些属于执行保障，尚未建立独立的质量或效率收益证据。

## 3. 数据与训练设置

| 项目 | 设置 |
|---|---|
| 数据 | nuScenes mini / scene-0061 / processed_10Hz/mini/000 |
| 采样 | interpolate_N=4，名义 10Hz；191 个目标时刻，相机使用最近真实图像，对象轨迹插值 |
| 图像 | 6 相机、1,146 张；原始 1600×900，加载缩放 3，约 533×300 |
| 训练集 | 172 个时刻，1,032 张图像 |
| 留出集 | 第 10、20、…、190 时刻，共 19 个时刻、114 张，同一时刻六视角一起留出 |
| 输入 | RGB、LiDAR、实例、天空/动态掩码、SMPL 姿态与 neutral 模板 |
| 分割 | SegFormer B5 Cityscapes 预训练模型；动态语义与官方粗框掩码取交集 |
| 配置 | omnire_extended_cam.yaml，seed=0，batch_size=1 |
| 训练结束 | 模型 step=29,381（从 0 编号），按时间预算退出；配置目标 40,000 步未完成 |
| 环境 | Tesla V100-SXM2 32GB；Python 3.9.25，PyTorch 2.0.0+cu118，CUDA 11.8 |
| 关键依赖 | gsplat 1.3.0、PyTorch3D 0.7.5、nvdiffrast 0.3.1 |

留出图像不参与 RGB 优化损失，但初始化沿用整个场景的加载流程，可使用留出时刻的几何、对象和图像投影信息。本轮不属于完全未接触留出时刻信息的严格泛化协议。

## 6. 有效性、原因与限制

**已验证：** 处理后数据完整，模型可训练和恢复，存在正式评估指标和可回放效果视频，可作为历史参考。

**尚未验证：** 没有算法对照组、多个种子或多个场景，不能判断某项改动带来了多少收益，也不能给出经过验证的收益原因。

历史训练使用 model-only 检查点，恢复时重建优化器，并包含 SMPL 缓存和 Adam 空状态兼容修复。后续对照须固定恢复策略和保存时机。相关历史补丁并不意味着已经应用到当前 Fork。

源码来源记录固定了下载 ZIP 的 SHA256，但未明确对应的 Git commit；后续实验前仍需将源码快照和当前仓库对齐。当前材料没有统一测得的渲染 FPS、独立三维几何误差或多场景稳定性结果。
