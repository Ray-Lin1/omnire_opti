# EXP-003：晚期重新开放背景增密

状态：已完成。分支：`codex/exp-003-bg-densify`。运行源码：`4d391e7`。

## 方法

与 EXP-001 相同的初始化、分辨率、划分、种子和学习率。仅将背景停止增密步数从 20,000 改为 35,000，增密梯度阈值仍为 `3e-4`。这是恢复后重新增密，不是从头延长增密。

[完整配置](../../configs/experiments/exp-003-bg-densify.yaml)

## 留出集结果

| 步数 | 续训对照 PSNR / SSIM / LPIPS | 本组 PSNR / SSIM / LPIPS | 原始指标 |
|---|---|---|---|
| 35,000 | 24.397171 / 0.773258 / 0.200128 | 23.407332 / 0.752195 / 0.214744 | [JSON](exp-003-bg-densify/metrics_test_35000.json) |
| 40,000 | 24.358997 / 0.762057 / 0.195538 | 24.283904 / 0.763419 / 0.188899 | [JSON](exp-003-bg-densify/metrics_test_40000.json) |

35,000 步显著退化；40,000 步 LPIPS 比对照降低约 0.00664，PSNR 低约 0.0751 dB。新增参数需要后续优化是可能解释，尚未通过独立消融证明。
